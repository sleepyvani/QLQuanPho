# Thư mục Resources

Thư mục này chứa các file tài nguyên cho ứng dụng, bao gồm logo và hình ảnh.

## Logo

Để thêm logo cho quán phở:

1. Đặt file ảnh logo vào thư mục này với tên `logo.png`
2. Hoặc sử dụng các định dạng khác: `logo.jpg`, `logo.bmp`
3. File logo sẽ tự động được load khi chạy ứng dụng

**Lưu ý:**
- Kích thước khuyến nghị: 200x200px hoặc lớn hơn (tỷ lệ 1:1)
- Định dạng khuyến nghị: PNG (hỗ trợ trong suốt)
- Nếu không có file logo, ứng dụng sẽ hiển thị text "PHỞ" làm placeholder

## Các file khác

Bạn có thể thêm các hình ảnh khác vào thư mục này nếu cần.
